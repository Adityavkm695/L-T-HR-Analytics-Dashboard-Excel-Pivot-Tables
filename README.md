# 📊 L&T HR Workforce Analytics Dashboard

An **HR Analytics portfolio project** built in Microsoft Excel using a dummy employee dataset to analyze workforce, compensation, performance, training, tenure, hiring trends, and employee distribution.

> ⚠️ **Disclaimer:** This project uses completely dummy/synthetic data for learning and portfolio purposes and does not contain confidential L&T information.

## 🎯 Project Objectives

* 👥 Analyze employee demographics & workforce
* 🏢 Compare departments and locations
* 💰 Analyze salary & bonus
* ⭐ Study performance ratings
* 📚 Analyze training hours
* ⏳ Analyze employee tenure
* 📅 Track hiring & exits
* 📊 Create an interactive HR dashboard

## 📋 Dataset

The dataset contains **~10,000 dummy employee records** with fields including:

`Employee ID` • `Gender` • `Age` • `Department` • `Employment Type` • `Job Title` • `Hire Date` • `Exit Date` • `Years of Service` • `Salary` • `Bonus %` • `Performance Rating` • `Training Hours` • `Location`

## 🛠️ Tools & Techniques

* Microsoft Excel
* Data Cleaning & Transformation
* PivotTables & PivotCharts
* Interactive Slicers
* KPI Cards
* Data Visualization
* HR Analytics

### 🔢 Excel Functions Used

`SWITCH()` • `VLOOKUP()` • `INDEX()` • `SORT()` • `SEQUENCE()` • `GETPIVOTDATA()` • `IFS()` • `DATEDIF()`

## 📊 Dashboard

The interactive dashboard provides:

* Total & Active Employees
* Average Salary & Age
* Average Training Hours
* Department & Gender Analysis
* Location Analysis
* Performance Analysis
* Tenure Analysis
* Hiring & Exit Trends
